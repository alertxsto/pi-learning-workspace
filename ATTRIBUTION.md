# Design references

The tutor instructions and skills in this repository are newly written for the agreed workspace flow, not a verbatim copy of third-party skills.

Design ideas reviewed:
- https://github.com/Mohamed-El-Sharqawy/agent-tutor — source-based learning, intake, honest feedback, review and durable notes.
- https://github.com/denismrvoljak/pi-tutor — hint-first, topic tracks and reflection.
- https://github.com/amphetamarina/spaced-agent — recall-first review (its FSRS/runtime code is not included).

Pi API and lifecycle patterns are based on the official documentation and extension examples (`prompt-customizer`, `interactive-shell`, `file-trigger`) shipped with @earendil-works/pi-coding-agent. No complete third-party implementation or skill has been copied. Retain appropriate third-party license notices if future work incorporates substantial source code.
